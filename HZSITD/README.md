# HZSITD - Department Official Correspondence Portal & Reference Implementation

This directory contains the legacy and reference architecture for the HZSITD (Hadiya Zone Science and Information Technology Department) correspondence management system.

## Reference Backend Server
- `backend/server.js`: Reference Express & SQLite API server (port 8000)
- `backend/db.js`: Database schema and SQLite initializations
- `backend/seed.js`: Reference seed data for department letters, users, and tracking numbers

## Frontend Architecture
The production frontend has been migrated to the modern Next.js 14 modular architecture located in `frontend/`.
